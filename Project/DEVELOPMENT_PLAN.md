# SMARTNEST Development Plan

**Owner:** Suma

## Phase 1 — Requirements and design
- Review the requirements and intended use.
- Confirm the target board and sensors only if hardware work is approved.
- Maintain architecture and class diagrams.

## Phase 2 — Java simulation
- Implement simulated sensor readings.
- Implement device-state simulation.
- Validate all user input and document test results.

## Phase 3 — Optional interface and storage
- Consider a GUI and local storage.
- Add unit tests and error handling.
- Keep secrets and personal data out of version control.

## Phase 4 — Future hardware evaluation
- Select suitable low-voltage development hardware.
- Test sensors independently before integration.
- Do not connect this starter program directly to household mains wiring.
- Any real appliance integration must use certified equipment and qualified supervision.

## Phase 5 — Evaluation
- Record observed results, limitations, and future improvements.
- Mark a feature complete only after it has been implemented and tested.
